## 5. Môi trường của agent

- Như v0.0.9. Thêm:
  - Trên máy Windows của chủ dự án, `npm run bench` cần `npm i --no-save playwright && npx playwright install chromium`, rồi tự chạy `npx vite preview --port 4173` trước `node bench/run.cjs` (script không tự bật server).
  - PR của Ian từ fork `ian-exnodes/3d-map` có `maintainerCanModify = true`: từ máy chủ dự án (SSH) push được vào nhánh fork để giải xung đột, rồi merge thẳng PR gốc. Fetch bằng `git fetch origin pull/<n>/head:pr-<n>`.
