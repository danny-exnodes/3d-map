## 1. Sản phẩm là gì

Tiny Map là web app mã nguồn mở (MIT). Người dùng **vẽ một khu trên bản đồ**, app **dựng mô hình thành phố 3D low‑poly** ngay trong trình duyệt từ dữ liệu mở. Mọi thứ chạy phía client, không có backend. Ý tưởng gốc lấy từ ảnh chụp sản phẩm "Tiny Map" do chủ dự án gửi: bản đồ nền tối, vẽ hình chữ nhật, panel tiến độ, mô hình pastel ban ngày, cửa sổ sáng đèn ban đêm, lớp giao thông màu xanh.

Người dùng và ngữ cảnh: chủ dự án là Danny (Cty Én Nam, TP.HCM). UI viết bằng tiếng Việt, khu vực ưu tiên là Việt Nam.

## 3. Kiến trúc (đọc theo thứ tự này)

```
main.ts ──► ui/MapView.ts (chọn vùng)
   │
   ├─► worker/client.ts ──postMessage──► worker/city.worker.ts
   │        loadCity()  : data/loader.ts
   │            ├─ loadOsm        data/osm.ts (Overpass: status, stream, timeout, slim) + data/cache.ts
   │            │     └─ lỗi/treo ⇒ loadOvertureContext   data/overtureBase.ts
   │            ├─ loadOvertureBuildings                  data/overture.ts (PMTiles z14)
   │            ├─ loadHeightGrid                         data/heights.ts (public/heights/ | /api/heights)
   │            └─ mergeOverture + applyHeightGrid + computeStats   data/enrich.ts
   │        buildCity()  : scene/buildCity.ts  (clip → roads → buildings → landscape)
   │            └─ serializeObject() ⇒ transfer typed arrays      scene/serialize.ts
   │
   └─► scene/CityScene.ts  (deserialize, Traffic, ánh sáng, bloom, chọn nhà, GLB)
```

Các file quan trọng:

| File | Vai trò |
| --- | --- |
| `src/data/types.ts` | Hợp đồng dữ liệu `CityData`, `Building` (`heightSource`, `footprintSource`, `archetype`, `tagged`) |
| `src/data/buildings.ts` | Tag → Building: kiến trúc mẫu VN, heuristic số tầng, kiểu mái, `restyle()` sau khi đổi chiều cao |
| `src/scene/buildings.ts` | Mọi nhà trong **1 mesh**; shader cửa sổ / vật liệu / nguồn / chọn. `aSeed` = `heightSource + 4×material + fraction`; `aBid` = chỉ số nhà |
| `src/scene/roofs.ts` | `minAreaRect` (rotating calipers), `buildRoof` |
| `src/scene/colorMode.ts` | `uMono` dùng chung, `patchMaterial`, `bakeMono` (GLB) |
| `src/config.ts` | `DEFAULT_LOCATION`, `EXAMPLE_BBOX` |
| `tools/lib/gob.mjs` | Trích lưới chiều cao Google 2.5D (Node; GeoTIFF UTM, không có CORS) |
| `tools/snapshot.ts` | Snapshot `CityData` cho bản xem thử (`npx tsx`) |
| `bench/run.cjs`, `bench/budget.json` | Benchmark và ngân sách hiệu năng chạy trên CI |

Quy ước toạ độ: `LocalProjection` đặt gốc ở tâm bbox, **x = đông, z = nam, y = lên**, đơn vị mét. Lưới chiều cao dùng cùng phép chiếu với bbox của chính lưới đó.

## 4. Nguồn dữ liệu và giới hạn đã biết

| Nguồn | Truy cập | Ghi chú |
| --- | --- | --- |
| Overpass (OSM) | 3 mirror công cộng, POST | Hay quá tải: đã có timeout từng mirror (4 s / 10 s / 10 s) và tổng 20 s. Cache 7 ngày |
| Overture `2026-10-21.0` | `https://tiles.overturemaps.org/<release>/{buildings,transportation,base}.pmtiles` | CORS `*`. buildings z14, transportation z14, base z13. **Gần như không có chiều cao ở VN** |
| Google Open Buildings 2.5D (2023) | `storage.googleapis.com/open-buildings-temporal-data/v1/geotiffs/...` | **Không có CORS** ⇒ phải tiền xử lý. Chỉ mục 3.143 tile VN ở `tools/data/gob-vnm-2023-index.json`. Band: 0 count, 1 height (m), 2 presence |
| Open‑Meteo | client | Thỉnh thoảng trả 429 (rate limit); cache 15 phút |

**Chiều cao trên GitHub Pages chỉ có cho 2 vùng dựng sẵn** (`public/heights/ngatuso`, `ennam`). Vùng khác dùng heuristic, cho tới khi làm proxy ở #4 hoặc chạy `npm run heights`. Khi chạy `npm run dev`, endpoint `/api/heights` tính được cho mọi vùng ở VN.

Đã biết, chưa sửa:
- **Chưa từng chạy với Overpass thật.** Sandbox phát triển của agent bị chặn Overpass; mọi kiểm thử OSM đều dùng mock. Cần chủ dự án hoặc một môi trường khác xác nhận.
- `DEFAULT_LOCATION` hiện là **trung điểm đường Châu Thị Hoá** (10.73776, 106.67637), vì OSM chưa có số nhà 101. Đang chờ toạ độ chính xác.
- Overture không có cây điểm ở 2 khu mẫu. Cây hiện có là cây được trồng thủ tục ven đường.
- Nhà chỉ có trong Overture không có tên hoặc địa chỉ.
- Mái chỉ được dựng cho footprint gần chữ nhật hoặc lồi; footprint lõm vẫn mái bằng (chưa có straight skeleton).

## 5. Môi trường của agent (quan trọng cho session cloud)

- **Overpass bị chặn** (connection reset). Nominatim, Overture, Google GCS, Open‑Meteo, CARTO, npm, PyPI và raw.githubusercontent.com truy cập được.
- Chromium và Playwright có sẵn (`require('playwright')`). **Không** cài thêm Playwright vào repo. CI cài riêng bằng `npm i --no-save playwright`.
- Node 22.22: chạy được `.ts` trực tiếp, trừ khi import không có đuôi. Script trong `tools/` import `src/` thì chạy bằng `npx tsx`.
- Không có `gh`. Dùng các tool `mcp__github__*`.
- **Artifact claude.ai chặn mọi request ra ngoài.** Vì vậy bản xem thử dùng snapshot (xem mục 7).

## 6. Quy trình làm việc đã thống nhất

- **PO ↔ TechLead**: mỗi tính năng là một issue. PO đề xuất phạm vi và tiêu chí nghiệm thu; TechLead phân tích kỹ thuật và rủi ro. Chỉ phát triển khi có bình luận "✅ PO đồng ý" **và** "✅ TechLead đồng ý". Chủ dự án đã giao toàn quyền cho hai vai trò này (đều do agent đóng). Quyết định cuối thuộc chủ repo.
- **Label**: `status: discussion` → `status: ready` → `status: done` (sau đó đóng issue khi đã merge và deploy); `status: backlog` cho việc đã chốt hoãn.
- **Nhánh**: nhánh mặc định là `master`. Mỗi việc làm trên nhánh `feature/*` hoặc `fix/*`, mở PR, chờ CI xanh rồi merge (kiểu merge commit). Push vào `master` sẽ tự deploy GitHub Pages.
- **Commit**: theo kiểu conventional (`feat:`, `fix:`, `perf:`, `ci:`, `docs:`), có dòng `Refs #n`, cuối message có `Co-Authored-By` và `Claude-Session`.
- **Mọi bình luận GitHub** của agent kết thúc bằng footer `_Generated by [Claude Code](https://claude.ai/code)_`.
- **Trước khi push**: `npm run typecheck && npm test && npm run build`. Với thay đổi về hiển thị, chạy Playwright chụp ảnh và tự xem lại. Với thay đổi về hiệu năng, chạy `npm run bench` (cần `vite preview` ở cổng 4173).

## 7. Lệnh hay dùng

```bash
npm ci
npm run dev                      # http://localhost:5173 (+ /api/heights)
npm test                         # 45 test (vitest)
npm run build && npx vite preview --port 4173 &   # rồi:
npm run bench                    # ngân sách: bench/budget.json
npm run heights -- --id <id> --name "<tên>" --bbox s,w,n,e     # lưới chiều cao → public/heights/
npx tsx tools/snapshot.ts --id <id> --name "<tên>" --bbox s,w,n,e --heights <id>   # → public/snapshots/
VITE_PREVIEW=1 npx vite build --outDir dist-preview            # bản xem thử offline
```

URL hữu ích: `?demo` (thành phố mẫu), `?demo&bench` (benchmark), `?style=mono`, `?nooverture`, `#bbox=s,w,n,e`.

Bản xem thử trên claude.ai: https://claude.ai/artifact/G8LajYYR2ogDxeLpTqh73a (riêng tư, chỉ chủ dự án mở được). Cách cập nhật:
1. Build `dist-preview`, xoá thư mục `heights/` trong đó.
2. Bỏ các thẻ `doctype/html/head/body` khỏi `index.html` và inline CSS vào trang.
3. Publish trang kèm `assets/*` và `snapshots/*` làm supporting files.
